who I am

About Me

I'm a Senior Software Engineer at Omobio (Pvt) Ltd in Sri Lanka. I joined in 2023 as a trainee full stack developer and today lead the team behind the Banglalink SMSC platform, which carries SMS traffic for one of Bangladesh's largest operators.

My work sits where telecom, data and the web meet: gateways that handle tens of thousands of messages a second, pipelines that turn their records into reports and bills, and the portals people use every day. I've delivered for Banglalink, Mobitel, Airtel, Ncell, Hutch and Hemas Hospital.

featured project

Reporting & Billing Engine

For an SMS messaging hub, I designed the backend that turns huge volumes of message events into fast reports and accurate billing data. Complex maths runs once per minute; every higher level just sums the one below. A small Python engine serves 70 reports to the PHP application through one simple JSON contract.

how I work

Techniques & Tips

Aggregate once

Do the expensive calculation at the smallest time grain, then let every larger report roll up from it. Reports stay fast as data grows.

ClickHouse · Materialized views

One simple contract

Every report takes JSON in and returns JSON out, with pagination, totals and safe parameter binding, so any app can call any report the same way.

Python · PHP · SQL

Guard the main branch

Conventional Commits checked locally and on GitHub, SonarQube on every change, and auto-migrations in Docker so new teammates start in one command.

Docker · SonarQube · Git
